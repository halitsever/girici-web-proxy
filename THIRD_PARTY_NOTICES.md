## Bundled dependencies

The web UI bundle includes Vue (MIT), Bootstrap CSS (MIT) and the Geist font (OFL-1.1); the font's license ships at
`/_g/ui/geist-OFL.txt`. The server depends on Express (MIT). The other license texts ship with their npm packages.

The engine bundles (`/_g/sw.js`, `/_g/client.*.js`, `/_g/worker.*.js`) include tldts and tldts-core (MIT), meriyah (ISC), magic-string (MIT),
@jridgewell/sourcemap-codec (MIT), htmlparser2 (MIT), entities (BSD-2-Clause), tough-cookie (BSD-3-Clause)
and idb (ISC). The build writes their license texts
to `/_g/THIRD_PARTY_LICENSES.txt`.
